# AprendiendoTrading.com 🚀

> **Plataforma Web Oficial & Academia de Trading Institucional en Oro (XAU/USD)**  
> Desarrollado por [FastPagePro](https://fastpagepro.com) • Especialistas en Sitios Web de Alta Conversión.

---

## 🛠️ Stack Tecnológico

- **Framework:** Next.js 16 (App Router + Turbopack)
- **UI & React:** React 19 + TypeScript
- **Estilos:** Tailwind CSS v4 + Lucide React Icons
- **Integraciones Financieras:**
  - TradingView Advanced Real-Time Chart Widget (XAU/USD M5)
  - Exness Partner & Affiliate Tracking
  - Simulador Cuantitativo Interactivo de Loteaje y Beneficio
  - Smart Auto-Hiding Navbar & Immersive Mobile Slide-Over Drawer
  - Floating WhatsApp Official Action Button
  - JSON-LD Schema.org (Course & EducationalOrganization) para Rich Snippets en Google

## 🚀 Despliegue en Producción (Vercel)

1. Conecta este repositorio en [Vercel](https://vercel.com).
2. Configura las variables de entorno en el panel de Vercel:
   - `NEXT_PUBLIC_SITE_URL=https://aprendiendotrading.com`
   - `NEXT_PUBLIC_EXNESS_AFFILIATE_URL=https://one.exness-track.com`
   - `NEXT_PUBLIC_WHATSAPP_NUMBER=+51933667414`
3. Despliega con un solo clic.
